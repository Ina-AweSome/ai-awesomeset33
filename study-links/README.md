# 📚 司法試験 復習リンク ジェネレーター

Obsidian ×リマインダーの間隔反復（3日後・7日後）で使う**復習リンク**を、
**壊れない・キーワードに直行する**形に作り直すためのツールです。

## いまの問題（このツールが直すこと）

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| 「ファイル … が見つかりません」でリンクが切れる | `obsidian://open?…&file=フルパス` は**パス指定**。ファイルを移動・リネーム・削除すると切れる | パスに依存しない**検索リンク**に変える |
| 開いても目的のキーワードを探すのにスクロールが疲れる | 長いノートの先頭が開くだけ | 検索リンクなら押した瞬間に**キーワード一致箇所が一覧**で出る |
| 関連ノートを1つ1つ探すのがしんどい | 1リンク＝1ファイル固定 | 検索なので **vault 全体（20study 含む）から関連が一括**で出る |

## 使い方

1. `study-links/index.html` を iPad の Safari 等で開く（オフラインで動作）。
2. **Vault 名**を確認（初期値は `Time based-司法試験予備試験`）。
3. 関連を絞りたければ**フォルダー**に `20study` 等を入れる（任意）。
4. タブ①に**リマインダーのタイトル**を1行ずつ貼る → 「検索リンクを生成」。
   - 例：`第三者保管の要件` `無報酬受寄者の解除権` `転貸の許容性`
   - 末尾の「（3日後）」等は自動で外れます。
5. 各行の**コピー**でリンクを取り、リマインダーの本文（URL欄）に貼る。
6. すでに切れた古いリンクは**タブ②**に貼れば検索リンクに変換できます。

## 復習ダッシュボード（1ノートで全部）

134件を1件ずつ開くのが疲れるなら、生成結果の
**「ダッシュボードを.mdで保存」**で全トピックを1枚の Markdown ノートに書き出せます。

- 中身は `- [トピック](obsidian://search?...)` の一覧。**タップで検索→該当ノートへ直行**。
- 科目でまとめたいときは入力を `民法：第三者保管の要件` の形にすると、
  `## 民法` `## 刑事訴訟法` … と**科目ごとの見出し**に分かれます。
- 保存した `復習ダッシュボード.md` を Obsidian に取り込めば、
  **そのノートを開くだけで全トピックにワンタップ**でアクセスできます。
- 「Markdownでコピー」で、Obsidian のノートに直接貼り付けることもできます。

## 生成されるリンクの形

```
obsidian://search?vault=Time%20based-...&query=第三者保管の要件
```

フォルダー絞り込みを付けた場合：

```
obsidian://search?vault=...&query=path%3A%2220study%22%20第三者保管の要件
```

- `open?file=` と違い**ファイルが動いても切れません**。
- タップで Obsidian の検索が開き、一致ノートへ直接ジャンプできます。

## さらにピンポイントに飛びたいとき

Obsidian 側でトピックに**見出し**を付けておくと、検索結果の見出し行タップでその位置に着地します。
運用として「復習トピック＝見出し」に揃えると精度が上がります。

## 制約（正直な注意）

このツールは**リンクを生成するだけ**で、あなたの Obsidian vault の中身は読みません
（vault は端末側にあり、このリポジトリには入っていません）。
検索対象・関連の抽出は Obsidian 本体の検索が担います。
